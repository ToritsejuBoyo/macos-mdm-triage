# macOS MDM Supervision, UAMDM, and Bootstrap Token Guide

An enterprise architectural guide for Apple macOS management hierarchies.

---

## 1. Apple Management State Hierarchy

```
+-------------------------------------------------------------------------------+
|                        APPLE MANAGEMENT HIERARCHY                             |
+-------------------------------------------------------------------------------+
| Level 1: Unsupervised / Manual User-Enrolled MDM                              |
|   * Enrolled by downloading mobileconfig profile via Safari.                  |
|   * Cannot manage TCC, System Extensions, or deep security restrictions.      |
|   * User can remove MDM profile at any time in System Settings.               |
|                                                                               |
| Level 2: User Approved MDM (UAMDM)                                            |
|   * User explicitly clicked "Approve" in System Settings -> Profiles.         |
|   * Enables PPPC / TCC management and silent certificate deployments.         |
|                                                                               |
| Level 3: Apple Supervised (Automated Device Enrollment / ADE via ABM)        |
|   * Mac assigned in Apple Business Manager (ABM) / Apple School Manager (ASM).|
|   * Zero-touch out-of-box enrollment via Setup Assistant.                     |
|   * Non-removable MDM profiles, full supervision lock, remote wipe authority. |
+-------------------------------------------------------------------------------+
```

---

## 2. The Apple Silicon Bootstrap Token

On Apple Silicon (M1, M2, M3, M4) Macs:
- **What it is:** A secure cryptographic token generated by macOS and escrowed to the MDM server.
- **Why it matters:** Required to authorize kernel extensions, software updates, and FileVault volume ownership without prompting for local administrator credentials.
- **Verification Command:**
  ```bash
  profiles status -type bootstraptoken
  ```
- **Escrow Command:**
  ```bash
  sudo profiles install -type bootstraptoken
  ```

## 3. Apple Push Notification Service (APNs) Troubleshooting

All MDM commands (Jamf, Intune, Kandji) depend on APNs:
1. **Network Requirements:**
   - Outbound TCP port **5223** to Apple's `17.0.0.0/8` block.
   - Outbound TCP port **443** fallback.
2. **Diagnostic Log Filter:**
   ```bash
   log show --predicate 'subsystem == "com.apple.apsd"' --last 15m
   ```
3. **Common Failures:**
   - Wi-Fi firewall blocking port 5223.
   - Expired MDM APNs push certificate on the MDM server.
